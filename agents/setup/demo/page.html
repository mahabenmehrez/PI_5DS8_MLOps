Setup Agent — demo (P1)

The agent that makes the project ready for the other agents: it generates the missing files (Makefile, CI, configuration), tests them on a sample, and fixes its own errors (3 attempts at most). Each button runs the real agent on a copy of the project: nothing is computed in advance.

checking the models…
Step 1

Analyse the project

The agent reads the code and the data, without changing anything: which script trains, which column to predict, which Python version, which files are missing, and what is wrong in the others' files (reported to their owner, never fixed in their place).

Step 2

Build the pipeline

The agent generates the files, then runs a dry run: make all SAMPLE=1 on a sample of the data, in a fresh environment. It writes the files only if everything passes.

Step 3

Break and repair

An error is added to the training script of the copy, then we watch the agent work: it reads the error, tries its rules, searches its memory and the web (Corrective RAG), asks the LLM for a fix, and checks every fix with a new dry run.

Step 4

Evaluation results

The recorded measurements (files in agents/setup/eval/results/): the final test on errors never seen, agent frozen; the cascade; the RAG metrics. 95% confidence intervals.
